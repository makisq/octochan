# Документация octochan

octochan (`ochan`) — минималистичный оркестратор для командной строки и CI.
Сценарии на языке алиасов со строгими типами, план до выполнения, заявки с
согласованием, откат, роли, серверный режим и слой для нейросетей.
Версия — `0.2.0-alpha` (`ochan --version`), что в ней есть — в
[CHANGELOG](../CHANGELOG.md).

## С чего начать

1. [Установка и настройка](guide/install.md) — сборка, рабочие каталоги, `config.yaml`.
2. [Как устроен ochan](guide/concepts.md) — источники, план, заявка, журнал, откат, роли, модули.
3. [Кукбук](cookbook/README.md) — готовые рецепты под конкретные задачи.
