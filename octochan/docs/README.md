# Документация octochan

octochan (`ochan`) — минималистичный оркестратор для командной строки и CI.
План до выполнения, заявки с согласованием и порядком, выполнение ровно
согласованного, откат и обратное действие, цели из инвентаря, выполнение
без человека по отзываемой политике, роли, песочница ядра, сервер с парой
primary/standby, контур HA-AI без человека с free и инцидентами, триггеры
CI, реестры пакетов и слой для нейросетей с формальным промптом.
Версия — `0.3.0-alpha` (`ochan --version`), что в ней есть — в
[CHANGELOG](../CHANGELOG.md).
