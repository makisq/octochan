# Кукбук octochan

Рецепты под конкретные задачи: что сделать, что получится и почему так.
Каждый рецепт прогнан на ochan; выводы — настоящие, пути и адреса
сокращены. Где шаг — запрос к API поставщика модели, это сказано в
рецепте.

| Рецепт | Задача |
|---|---|
| [Дрейф конфигурации в CI](ci-drift.md) | CI падает, если конфиг разошёлся с эталоном; сценарии и промпты проверяются до слияния |
| [Правка конфига через заявку](change-approval.md) | изменить боевой конфиг с согласованием, документом и откатом |
| [Раскатка на группу серверов](rollout.md) | один сценарий — конфиги для серверов из инвентаря, `--limit`, отчёт, заявка, откат |
| [Новые серверы без человека](new-servers.md) | `ochan watch` находит новые хосты, по политике выполняет сам, остальное — заявки |
| [Нейросеть пишет сценарий по формальному промпту](ai-script.md) | поручить модели задачу так, чтобы она не вышла за правила, слоты и отчёт |
| [Разбор журнала PostgreSQL](log-triage.md) | найти важное в журнале: уровни, сводка, свои правила |
| [Роли для команды и CI](team-roles.md) | стажёр только смотрит, CI планирует, ведущий согласует |
| [Общий оркестратор](shared-orchestrator.md) | один ochan на сервере, команда подключается по сети |
| [Общий сервер против чужой роли](hardened-server.md) | чужой с паролем роли не выйдет за свои файлы, не согласует сам себе, а следы не сотрёт |
| [Пара серверов и агенты](ha-pair.md) | primary и standby, переключение без двойного выполнения, машины-агенты как инвентарь |
| [Модель в облаке и конфиги на своей машине](remote-llm.md) | Claude API, OpenAI, ChatGPT, Gemini работают с конфигами через MCP по HTTP |
| [Две правки одного конфига](morphisms.md) | морфизмы: проверить до выкатки, что итог не зависит от порядка правок, и перенести правку в пул соединений функтором |
| [Свой пакет алиасов как скилл](skill-package.md) | библиотека сценариев с версией, на которую ссылается промпт |
| [ochan на своём языке](translate.md) | перевести справку на немецкий, японский, любой |
| [Свой модуль команд](command-module.md) | добавить в ochan новую команду на Go |

Справка по каждой команде — в [справочнике](../reference/commands.md),
устройство — в [руководстве](../README.md).
