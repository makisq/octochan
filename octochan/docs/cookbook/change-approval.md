# Правка конфига через заявку

**Задача.** Поднять `max_connections` и `work_mem` на боевом сервере. Правку
нужно согласовать, приложить документ, выполнить ровно согласованное и
уметь вернуть.

## 1. Что изменится

```
$ cat changes.conf
max_connections = 200
work_mem = 8MB

$ ochan plan prod.conf changes.conf
План: changes.conf -> prod.conf

Изменений: 2

  prod.conf
    изменить   max_connections: 100 -> 200
    изменить   work_mem: 4MB -> 8MB
```

## 2. Заявка с документом

```
$ ochan request prod.conf changes.conf --doc заявка.docx
Заявка 2fb5c48ac0 создана (ждёт решения)
Изменений: 2
Документ: заявка.docx
Согласовать: ochan approve 2fb5c48ac0
```

`заявка.docx` — обычный Word-файл: шапка, поля, таблица изменений. Его
можно отправить на подпись. С `--notify` (или `defaults.notify_always`)
уходит письмо — см. [«Почта»](../guide/requests.md#почта).

## 3. Решение

```
$ ochan requests
2026-10-23 10:54  2fb5c48ac0  ждёт решения  prod.conf  правка prod.conf, параметров: 2

$ ochan approve 2fb5 --comment "окно с 02:00"
Заявка 2fb5c48ac0: согласована (dba)
Выполнить: ochan apply --request 2fb5c48ac0
```

Отказ — `ochan reject 2fb5 --reason "нет окна"`. Решение принимается один
раз: пересмотр — новая заявка.

## 4. Выполнение

```
$ ochan apply --request 2fb5
Заявка 2fb5c48ac0 выполнена: /srv/pg/prod.conf, изменено параметров: 2
Откат: ochan rollback 7a8feb67f3
```

Применяются изменения из заявки — не перечитанный `changes.conf` — к тому
файлу, где согласовали, из какого бы каталога ни запускали. Если кто-то
успел поправить параметр, выполнение отменяется:

```
ошибка: /srv/pg/prod.conf изменился после согласования заявки 2fb5c48ac0: правка легла бы не на то, что согласовали; оформите новую заявку.
  max_connections: при согласовании 100, сейчас 150
```

## 5. Если нужно вернуть

```
$ ochan rollback 7a8f
/srv/pg/prod.conf восстановлен из записи 7a8feb67f3 (откат записан как d22a0e3542)
```

Сам откат тоже записан и тоже обратим.

## Подводные камни

- Файл пишется заново, как и `patch`: комментарии и порядок строк
  conf-файла не сохраняются. Нужно сохранить комментарии — правьте файл
  сценарием на языке алиасов только там, где это допустимо, или держите
  комментарии в репозитории, а не в боевом файле.
- Правку живого источника (`postgres://…`) ochan не записывает: её
  выполняют на сервере, например `ALTER SYSTEM`. План и заявка для неё
  работают — согласовать можно, выполнить — нет.
