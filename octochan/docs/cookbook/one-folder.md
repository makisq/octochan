# Одна папка: поставить ochan там, где больше нигде нельзя

**Задача.** На машине политика разрешает работать и запускать программы
только в одной папке. `~/.local/bin` недоступен, а из `~/.octochan/modules`
модуль не запускается (`operation not permitted`) — `!!install` отказывает.
Нужно, чтобы ochan жил в этой папке целиком и находил своё сам, без
`export` в каждом окне.

## Установка

Из исходников — в папке, где разрешено работать:

```
$ make install HERE=1
Программы:        /srv/work/octochan
Рабочий каталог:  /srv/work/octochan/.octochan
Модули:           /srv/work/octochan/.octochan/modules (в рабочем каталоге)
…
Установлено: /srv/work/octochan/ochan
Установлено: /srv/work/octochan/ochan-mcp
Указатель: /srv/work/octochan/ochan.home → .octochan (путь от папки программы: её можно переносить целиком)
Файлы для нейросети: /srv/work/octochan/work — ask и opmode llm читают только её (config.yaml: llm.chat.root: [work])

Рабочий каталог      /srv/work/octochan/.octochan
                       файл ochan.home рядом с программой
…
Запуск: ./ochan из папки /srv/work/octochan
```

Без `HERE=1` установка спросит — «1» и «да»:

```
$ make install
Установка ochan. Как ставить?
  1 — быстрая: всё в этой папке — /srv/work/octochan
      программы, рабочий каталог (.octochan) и модули; ochan находит своё сам
  2 — ручная: каждый путь задаёте сами, Enter — путь по умолчанию
Выбор, 1 или 2: 1
…
Значок в меню приложений и на рабочем столе? да или нет [нет]:
Установить? да или нет [да]:
```

Без исходников и без `make` — готовая программа ставит себя сама: положите
`ochan` и `ochan-mcp` в папку и выполните `./ochan setup --here`. Ответы
можно подать и конвейером: `printf '1\n\nда\n' | ./ochan setup`.

## Что получилось

```
/srv/work/octochan/
  ochan, ochan-mcp     программы
  ochan.home           указатель: где рабочий каталог
  .octochan/           рабочий каталог: роли, заявки, журнал аудита, конфиг, модули
  work/                файлы, с которыми работает нейросеть
```

`ochan.home` — одна строка с путём. Путь без начала от корня считается от
папки программы, поэтому папку можно переносить и копировать целиком:

```
$ mv /srv/work/octochan /srv/work/ochan-2 && cd /srv/work/ochan-2
$ ./ochan paths
Рабочий каталог      /srv/work/ochan-2/.octochan
                       файл ochan.home рядом с программой
```

Модули теперь ставятся в папку, где запуск разрешён:

```
$ ./ochan '!!install' ./rlm.hcplugin
```

## Что учесть

- **Папка должна быть вашей.** Если она или каталог над ней открыты для
  записи группе или остальным, ochan откажется работать и скажет, что
  закрыть: `chmod go-w /srv/work/octochan`. Иначе другой пользователь
  подложил бы в модули свой плагин.
- **Переменные окружения сильнее указателя.** Остался `export
  OCTOCHAN_HOME=…` в профиле — установка предупредит о нём: уберите, и
  ochan возьмёт записанные пути.
- **Годится всё, кроме модулей?** Тогда не одна папка, а ручная установка:
  `make install MODULES_DIR=/opt/ochan/modules` — или строка `paths.modules`
  в `config.yaml`.
- **Значок** — `./ochan setup --desktop=only`: запись в меню приложений и
  ярлык на рабочем столе, если на машине это разрешено.
