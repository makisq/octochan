# Встроенные функции языка алиасов

Арность — сколько аргументов функция принимает; `…` — сколько угодно. Тип результата — тот,
что видит проверка до запуска (`ochan check`); «—» — узнаётся при выполнении.
Язык описан в [руководстве](../guide/language.md).

| Функция | Аргументы | Результат | Что делает |
|---|---|---|---|
| `config` | 1–2 | `config` | разобрать источник один раз: файл, текст или postgres://user@host/db |
| `diff` | 2 | `int` | количество расхождений между двумя конфигами |
| `diff_list` | 2 | `list` | список имён расходящихся параметров |
| `env` | 1–2 | — | значение переменной окружения |
| `exists` | 1 | `bool` | существует ли файл |
| `fail` | 0… | — | прервать сценарий с сообщением |
| `file` | 1 | `stream` | поток в файл: print дописывает в него строку; запись — как write, видна в плане |
| `get` | 2–3 | — | значение по ключу либо значение по умолчанию |
| `has` | 2 | `bool` | есть ли ключ в словаре или параметр в конфиге |
| `int` | 1 | `int` | привести к целому |
| `join` | 1–2 | `string` | склеить список в строку |
| `keys` | 1 | `list` | ключи словаря или имена параметров конфига |
| `len` | 1 | `int` | длина списка или строки |
| `lines` | 1 | `list` | разбить текст на список строк |
| `list` | 0… | `list` | собрать список из аргументов |
| `map` | 0… | `map` | собрать словарь из пар ключ, значение |
| `merge` | 2 | — | объединить два словаря или конфига; правый перекрывает левый |
| `normalize` | 1 | `string` | каноническая форма значения конфига: normalize("8GB") == normalize("8192MB") |
| `param` | 2–3 | `string` | значение параметра конфига: param(файл, имя) или param(файл, секция, имя) |
| `params` | 1 | `int` | количество параметров в конфиге |
| `print` | 0… | `string` | напечатать значения; первым аргументом можно передать поток: print(file("отчёт.txt"), …) |
| `put` | 3 | — | записать значение по ключу и вернуть контейнер |
| `read` | 1 | `string` | содержимое файла |
| `save` | 2 | `int` | записать конфиг в файл |
| `stderr` | 0 | `stream` | поток ошибок |
| `stdout` | 0 | `stream` | поток вывода на экран — туда печатает print по умолчанию |
| `str` | 1 | `string` | привести к строке |
| `validate` | 1 | `int` | проверить конфиг, вернуть число параметров |
| `values` | 1 | `list` | значения словаря или конфига |
| `write` | 2 | `int` | записать текст в файл |
