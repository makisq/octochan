# Встроенные функции языка алиасов

Арность — сколько аргументов функция принимает; `…` — сколько угодно. Тип результата — тот,
что видит проверка до запуска (`ochan check`); «—» — узнаётся при выполнении.
Язык описан в [руководстве](../guide/language.md).

| Функция | Аргументы | Результат | Что делает |
|---|---|---|---|
| `abs` | 1 | — | модуль числа |
| `call` | 1… | — | вызвать функцию с аргументами: call(f, 1, 2) |
| `ceil` | 1 | `int` | округлить вверх до целого |
| `choice` | 1 | — | случайный элемент списка |
| `compose` | 1… | `fn` | функции по порядку применения: compose(f, g)(x) — это g(f(x)), то же, что f >> g |
| `config` | 1–2 | `config` | разобрать источник один раз: файл, текст или postgres://user@host/db |
| `contains` | 2 | `bool` | есть ли подстрока в строке или элемент в списке |
| `curl` | 1–2 | `map` | ответ HTTP целиком: {status, headers, body}; method — GET или HEAD |
| `diff` | 2 | `int` | количество расхождений между двумя конфигами |
| `diff_list` | 2 | `list` | список имён расходящихся параметров |
| `each` | 2 | `list` | применить функцию к каждому элементу и собрать результаты: each(список, fn(x) => x * 2) |
| `ends_with` | 2 | `bool` | кончается ли строка суффиксом |
| `env` | 1–2 | — | значение переменной окружения |
| `eval` | 1 | — | вычислить выражение языка из строки: eval("2 + 3 * 4"); проверяется перед вычислением, алиасы недоступны |
| `exists` | 1 | `bool` | существует ли файл |
| `fail` | 0… | — | прервать сценарий с сообщением |
| `fetch` | 1–2 | `string` | тело ответа HTTP GET: fetch(url[, {"headers": {…}, "timeout": "10s"}]); в песочнице — только хосты из --allow-net |
| `file` | 1 | `stream` | поток в файл: print дописывает в него строку; запись — как write, видна в плане |
| `filter` | 2 | `list` | элементы, для которых функция истинна: filter(список, fn(x) => x > 0) |
| `float` | 1 | `float` | привести к дробному |
| `floor` | 1 | `int` | округлить вниз до целого |
| `format` | 1… | `string` | строка по образцу: format("id=%d, %s", n, имя); %d %f %.2f %s %v %q %x %t %% |
| `from_json` | 1 | — | разобрать JSON |
| `from_toml` | 1 | `map` | разобрать TOML |
| `from_yaml` | 1 | — | разобрать YAML |
| `get` | 2–3 | — | значение по ключу либо значение по умолчанию |
| `has` | 2 | `bool` | есть ли ключ в словаре или параметр в конфиге |
| `id` | 0 | `fn` | тождественная функция: id()(x) — это x |
| `int` | 1 | `int` | привести к целому |
| `join` | 1–2 | `string` | склеить список в строку |
| `keys` | 1 | `list` | ключи словаря или имена параметров конфига |
| `len` | 1 | `int` | длина списка или строки |
| `lines` | 1 | `list` | разбить текст на список строк |
| `list` | 0… | `list` | собрать список из аргументов |
| `lower` | 1 | `string` | строка в нижнем регистре |
| `map` | 0… | `map` | собрать словарь из пар ключ, значение |
| `max` | 1… | — | наибольшее: max(a, b, …) или max(список) |
| `merge` | 2 | — | объединить два словаря или конфига; правый перекрывает левый |
| `min` | 1… | — | наименьшее: min(a, b, …) или min(список) |
| `normalize` | 1 | `string` | каноническая форма значения конфига: normalize("8GB") == normalize("8192MB") |
| `now` | 0 | `string` | время запуска сценария (RFC 3339); в заявке — время построения плана |
| `param` | 2–3 | `string` | значение параметра конфига: param(файл, имя) или param(файл, секция, имя) |
| `params` | 1 | `int` | количество параметров в конфиге |
| `partial` | 2… | `fn` | закрепить первые аргументы: partial(fn put, c)("x", "1") — то же, что put(c, "x", "1") |
| `pow` | 2 | `float` | степень: pow(2, 10) |
| `print` | 0… | `string` | напечатать значения; первым аргументом можно передать поток: print(file("отчёт.txt"), …) |
| `put` | 3 | — | записать значение по ключу и вернуть контейнер |
| `rand` | 0–2 | — | случайное: rand() — дробное от 0 до 1, rand(n) — целое от 0 до n-1, rand(a, b) — от a до b; в заявке зерно фиксируется |
| `range` | 1–3 | `list` | список целых: range(n) — от 0 до n-1, range(a, b) — от a до b-1, range(a, b, шаг) |
| `read` | 1 | `string` | содержимое файла |
| `reduce` | 3 | — | свернуть список: reduce(список, fn(итог, x) => итог + x, 0) |
| `replace` | 3 | `string` | заменить все вхождения: replace(s, старое, новое) |
| `round` | 1–2 | — | округлить: round(x) — до целого, round(x, 2) — до сотых |
| `save` | 2 | `int` | записать конфиг в файл |
| `shuffle` | 1 | `list` | список в случайном порядке |
| `sleep` | 1 | `string` | пауза: sleep(2) — секунды, sleep("500ms"); в режиме плана не ждёт |
| `sort` | 1–2 | `list` | отсортировать список: sort(список) или sort(список, fn(x) => ключ); порядок равных сохраняется |
| `split` | 2 | `list` | разбить строку по разделителю: split("a,b", ",") |
| `sqrt` | 1 | `float` | квадратный корень |
| `starts_with` | 2 | `bool` | начинается ли строка с префикса |
| `stderr` | 0 | `stream` | поток ошибок |
| `stdout` | 0 | `stream` | поток вывода на экран — туда печатает print по умолчанию |
| `str` | 1 | `string` | привести к строке |
| `time.add` | 2 | `string` | время плюс длительность: time.add(now(), "1h30m") |
| `time.format` | 1–2 | `string` | время по образцу %Y-%m-%d %H:%M:%S: time.format(образец[, время]) |
| `time.now` | 0 | `string` | то же, что now() |
| `time.sleep` | 1 | `string` | то же, что sleep() |
| `time.unix` | 0–1 | `int` | секунды Unix: времени запуска или переданного времени |
| `to_json` | 1–2 | `string` | значение в JSON; to_json(x, true) — с отступами |
| `to_toml` | 1 | `string` | словарь в TOML |
| `to_yaml` | 1 | `string` | значение в YAML |
| `trim` | 1–2 | `string` | убрать пробелы по краям; trim(s, "/") — эти символы |
| `upper` | 1 | `string` | строка в верхнем регистре |
| `validate` | 1 | `int` | проверить конфиг, вернуть число параметров |
| `values` | 1 | `list` | значения словаря или конфига |
| `write` | 2 | `int` | записать текст в файл |
