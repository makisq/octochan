# Стартовая модель ℒ

Обученные веса своей модели, которые доставляются вместе с ochan: они
встроены в бинарник (`own/pretrained.go`), и `ochan llm init --pretrained
--out каталог` пишет их в каталог модели. Учить язык с нуля на каждой машине
незачем — модель отвечает сразу, без Python, видеокарты и сети.

| | |
|---|---|
| Модель | `own-small-2`: архитектура Llama, ширина 384, 8 слоёв, 6 голов, MLP 1024, контекст 1024; 14,8 млн параметров; вход и выход связаны |
| Словарь | `fpmtok.json`, 1 682 токена: алфавит ℒ, цифры, разметка строки, переменные имён частных случаев |
| Обучение | с нуля, только на ℒ: 65 002 пары «задача → ответ логики ochan», 8 эпох (`llama/train_own.py`). Чужих весов и чужих данных в ней нет |
| Веса | int8, по строкам (`ochan llm quantize --bits 8`): 56,5 → 14,2 МБ |
| Сверка с полными | тот же токен в 99,99 % позиций ответа на отложенных парах; ответы на 58 задачах (`experiment/sources`, `llama/tasks`) совпадают с полными во всех 58 |

## Что нужно знать

- **Параметров колец здесь нет.** Надёжность правил, история прочтений и
  кластеры инцидентов — свои у каждой установки: их считают `ochan llm fit`
  и `ochan llm learn` по её журналу. Стартовая модель начинает с условного
  счёта автора (8 из 8).
- **Ответ пишет логика, сеть выбирает порядок.** Решения модели выводит
  `fp.Derive` и проверяют кольца; сеть выбирает только среди допустимых
  утверждений. Поэтому изменения логики языка (например, перенос цепочкой,
  появившийся после обучения этих весов) действуют сразу, без переобучения.
  Сама сеть при этом отстаёт: на сегодняшнем корпусе её потери на ответе
  выше, чем на корпусе, на котором она училась (0,21 против 0,02 —
  вероятно, из-за конструкций, которых тогда в корпусе не было), а ответы
  модели — те же, что выводит логика. Переобучение на свежем корпусе
  подтянуло бы сеть; на ответы модели оно почти не влияет.
- **Словарь — на момент обучения.** Слова, которых в нём нет (свои словари
  оператора, слова скиллов), модель переносит как имена частных случаев.
- **Дообучение сети** идёт с полных весов: `ochan llm init --pretrained
  --full` распаковывает int8 в float32, дальше — `llama/train_own.py --init`.
- **Новая версия весов — новый файл в истории git** (14 МБ навсегда):
  обновлять стартовые веса стоит редко и по делу.
